# Roadmap

Este roadmap orienta contribuições; não representa compromisso de prazo.

## Agora — validação da versão 3

- Validar Cursor e Claude Desktop de ponta a ponta e registrar versões testadas.
- Validar a revisão MCP `2026-07-28` com mais clientes da comunidade.
- Validar o transporte `stdio` e a compatibilidade stateless da família 2025.
- Publicar a release `v3.0.0` após validação em uma conta Kommo de teste.
- Exercitar as novas tools de contatos/empresas/tarefas/busca/vínculo em conta de teste.

## Próximo

- Publicar o pacote no npm e a imagem no GHCR após validar conteúdo e provenance.
- Adicionar cobertura automatizada e smoke test da imagem publicada.
- Expandir custom fields tipados e tags nas tools de escrita.

## Futuro

- OAuth 2.1 para implantações multiusuário.
- Traces/spans opcionais além do endpoint `/metrics`.
- Documentação em inglês e exemplos adicionais de clientes MCP.

## Como ajudar

Procure issues com `good first issue` ou `help wanted`. Antes de iniciar uma
mudança grande, abra uma Discussion ou issue para alinhar a abordagem.
